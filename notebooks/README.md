# Notebooks

Use this folder for exploratory work and Colab imports. Keep notebook outputs small in git; `nbstripout` is installed for cleaning large outputs before committing.

Recommended naming:

```text
00_lecture_rebuild.ipynb
01_ex1_parallel_attention.ipynb
02_dataset_exploration.ipynb
```

When a notebook starts becoming reusable, move the code into `src/karpathygpt_hw/` or a homework exercise folder.
